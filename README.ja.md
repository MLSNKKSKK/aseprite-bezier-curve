# Aseprite 用ベジェ曲線拡張機能

[English](README.md) | 日本語

「曲線レイヤー」を追加する [Aseprite](https://www.aseprite.org/) の拡張機能です。曲線レイヤーの線はベジェ曲線で引かれ、いつでも編集できます。レイヤーを選ぶだけで、キャンバス上で点を動かしたり、曲がり具合・色・太さを変えたりできます。

- お絵かきアプリのペンツールのように、キャンバス上でクリック・ドラッグして描く。設定は小さなパネルにまとまっている
- 1つのレイヤーに何本でも線を引ける。色と太さ(1〜32px、丸ブラシ)は線ごとに設定できる
- 1px の線をきれいにするピクセルパーフェクトと、縁をなめらかにするアンチエイリアス(RGB・グレースケール)に対応
- 始点と終点をつないで閉じた形も作れる。内側を色で塗りつぶすこともでき、線なしで塗りだけにもできる
- 円・四角・角丸四角・三角・多角形・星の基本図形を配置できる
- フレームごとに別の線を持てる
- RGB・グレースケール・インデックスのどのカラーモードでも使える

## ベジェ曲線 Pro(有料版)

有料版の **ベジェ曲線 Pro** では、次の機能も使えます。

- **変形**:キャンバス上のボックスで図形を拡大縮小・回転・シアー・反転・移動できる。数値を入力しての変形もできる
- **コピー・貼り付け**:図形をほかのフレーム・レイヤー・スプライトにコピーできる
- **重なり順**:図形を前面・背面へ移動できる

販売ページは準備中です。無料版で描いた曲線は Pro でもそのまま編集でき、その逆もできます。Pro をインストールすると、無料版と入れ替わります。

## インストール

1. [最新のリリース](https://github.com/MLSNKKSKK/aseprite-bezier-curve/releases/latest)から `bezier-curve.aseprite-extension` をダウンロードします。
2. ダブルクリックします(Windows・macOS)。または Aseprite で **編集 > 環境設定 > 拡張機能 > 拡張機能を追加** を選び、そのファイルを選びます。

一度入れれば、Aseprite を起動するたびに使えます。メニューやメッセージは、Aseprite の表示言語に合わせて日本語か英語になります。外すときは、同じ拡張機能の画面で **アンインストール** を選びます。

## 使い方

**レイヤー > 新規 > 新しい曲線レイヤー** を選びます(タイムラインのレイヤーの右クリックメニューにもあります)。選択中のレイヤーのすぐ上に `曲線 1` というレイヤーができます。曲線レイヤーはタイムラインで緑色に表示されるので、ほかのレイヤーと見分けられます(以前の版で作った曲線レイヤーは、次に編集したときに緑色になります。自分でレイヤーの色を付けている場合は、その色のままです)。

曲線レイヤーを選んでいる間は、その線をキャンバス上で直接編集でき、ウィンドウの右端に小さなパネルが開きます。ホイールでの拡大縮小や、Space+ドラッグでのスクロールは普段どおり使えます。

| キャンバスでの操作 | できること |
| --- | --- |
| 何もないところをクリック | 新しい図形を描き始めます。図形を描いている途中(または図形を選択中)なら、その図形の最後に点を追加します。 |
| 何もないところから押したままドラッグ | 点を追加してハンドルを伸ばし、線を曲げます。 |
| 描いている図形の最後の点をクリック、または **Enter** | その図形の描画を終えます。次に何もないところをクリックすると、新しい図形を描き始めます。 |
| 描いている図形の始点をクリック | 図形を閉じて(最後の点を最初の点につないで)、描画を終えます。図形は選択されたままになります。 |
| 点をドラッグ | 点を動かします。 |
| ハンドルをドラッグ | 線の曲がり具合を変えます。反対側のハンドルも一緒に回ります(**ハンドル片側のみ** がオフのとき)。 |
| 線をクリック | その図形を選択します。選択中の図形の線をクリックすると、形を変えずにそこへ点を追加します。 |
| 塗りのある図形の内側をクリック | その図形を選択します(塗りが重なっているところでは、上にある図形)。塗りの上から新しい図形を描き始めたいときは、先に **新しく作図** を押します。 |
| 線や塗りの内側をドラッグ | 図形全体を動かします。 |
| 点をクリック | 点を選択します(白い枠で囲まれます)。 |
| **Delete** / **Backspace** | 選択中の点を削除し、その前の点を選択します(続けて押すと点を順に削除します)。点を選ばずに図形を選択しているとき(線や塗りをクリックしたときや、図形を閉じたとき)は、図形ごと削除します。 |
| **Ctrl+Z** / **Ctrl+Y** | 元に戻す / やり直す。まず最近の線への変更を戻し、そのあとは Aseprite の履歴を戻します。 |
| **Esc** | ドラッグ中の操作を取り消すか、図形の描画を終えて選択を解除します。 |

図形を描いている間は、クリックはすべてその図形への点の追加に使われ、ほかの図形はつかめません。ほかの図形の点から描き始めたり、線をまたいで描いたりできます。塗りの内側でも、クリックやドラッグで点を追加できます(ドラッグすると曲線の点になります)。描画を終えたあとは、ほかの図形の線をクリックするとその図形を選んで編集できます。

「確定」の操作はありません。ほかのレイヤーやフレームを選んだり、保存やフィルターなどほかのコマンドを使ったりすると、変更が Aseprite の元に戻す履歴に1回分として入ります(**編集 > 元に戻す** / Ctrl+Z)。保存すると、その時点の変更がすぐに反映されます(ガイドが保存されることはありません)。最初に変更を加えた時点でスプライトは「変更あり」になるので、タブを閉じると保存するか確認されます。曲線レイヤーをもう一度選べば、続けて編集できます。ファイルを保存して開き直したあとも同じです。

編集中は、点とハンドルが曲線レイヤーに明るい緑色で表示されます。点は中の空いた 3×3 ピクセルの四角で、真ん中に線が見えます(選択中の点は薄い緑、ほかの図形の点は濃い緑)。ハンドルは点線で、先端は塗りつぶした 3×3 ピクセルの四角です。点やハンドルの先端は、四角のどこをクリックしてもつかめます。

グレースケールのスプライトや、パレットに緑がないインデックスのスプライトでは緑を表示できないため、ガイドは白黒になります。点は角が黒・辺が白の中の空いた四角(選択中の点は逆)、ハンドルは白黒の点線で、ハンドルの先端は黒い縁取りに白い中心の四角になります。インデックスのパレットに明るい緑を足すと、ガイドは緑になります。レイヤーを離れると消えます。拡大表示で使うと操作しやすくなります。

パネルの上部には、作図・図形の配置・削除のボタンがあります。その下の大項目 **選択中の図形** には、選択中の図形の設定が並びます。その中は、図形のまわりの線の設定 **線** と、内側の設定 **塗り** の2つの小項目に分かれています。

| パネル | 説明 |
| --- | --- |
| **新しく作図** | 今の図形の描画を終えます。次のクリックで新しい図形を描き始めます。 |
| **図形を配置…** | 基本図形(円・四角・角丸四角・三角・多角形・星)を配置します。形(多角形と星は角の数、角丸四角は角の丸み)を選んでからキャンバス上をドラッグすると、ドラッグした範囲いっぱいに図形が入ります。ドラッグ中も形が表示されます。クリックだけなら標準の大きさで置きます。**縦横を同じにする** をオンにすると、正円・正方形・正多角形になります(スクリプトからは Shift キーを読めないため)。図形はパネルの設定で描かれる閉じた図形で、ほかの図形と同じように編集できます。Esc か Enter でやめます。 |
| **図形を削除** | 選択中の図形を削除します。 |
| **アンチエイリアス** | 線と塗りの縁を半透明のピクセルでなめらかにします。図形が重なるところは色が混ざります。RGB とグレースケールのみです。インデックスのスプライトでは半透明のピクセルを使えないため、オフになります。 |
| **線**: **描く** | オフにすると線を描かず、塗りだけになります。 |
| **線**: **色** | 線の色。最初は今の描画色になっています。 |
| **線**: **太さ** | 線の太さ(1〜32 ピクセル)。 |
| **線**: **ピクセルパーフェクト** | 1px の線の角にできる、重なったピクセルを取り除きます(図形の点そのものは残すので、四角の角などはきれいに残ります)。アンチエイリアスのときは使いません。 |
| **塗り**: **塗る** | 図形の内側を塗りつぶします。始点と終点をつないでいない図形は、両端を直線で結んだ形として塗ります。線は塗りの上に描かれます。 |
| **塗り**: **色** | 塗りつぶしの色。 |
| **ハンドル片側のみ** | ハンドルをドラッグしても反対側が回らなくなり、とがった角を作れます。 |
| **ガイド表示** | 点とハンドルの表示を切り替えます。図形だけの見た目を確かめるときに使います。 |
| **両端をつなぐ** | 選択中の図形の最後の点を、最初の点につなぎます。描いている途中の図形をつなぐと、その図形の描画も終わります(選択されたままになります)。 |
| **点を削除** | 選択中の点を削除します。 |
| **丸/角** | 選択中の点を、丸(ハンドルあり)と角で切り替えます。 |
| **元に戻す** / **やり直す** | 図形への変更を元に戻す / やり直す。 |
| **閉じる** | パネルを閉じてこのレイヤーの編集をやめ、Aseprite のツール(移動ツールなど)を使えるようにします。パネルの × ボタンで閉じても同じです。レイヤーを選び直すか、**レイヤー > 曲線を編集** でまた編集できます。 |
| **ラスタライズ** | 曲線レイヤーを普通のレイヤーにします(下を参照)。 |
| **ヘルプ** | 各項目の説明を一覧にしたヘルプを開きます(Aseprite のスクリプトではマウスを乗せたときのヒントを出せないため)。開いたまま編集を続けられます。 |

図形を選んでいるときは、項目にその図形の設定が表示され、変えるとその図形が変わります。図形を選んでいないときは、大項目の名前が **次に描く図形** になり、次に描く図形の設定になります(描いている途中は **図形を描画中** と表示されます)。

アニメーションの再生中も編集は止まり、Enter で再生を止めると再開します。

## ラスタライズ

**レイヤー > 曲線レイヤーをラスタライズ**(タイムラインの右クリックメニューや、パネルの **ラスタライズ** ボタンからも使えます)で、曲線レイヤーを普通のレイヤーにします。絵はそのまま残りますが、線を曲線として編集することはできなくなり、代わりに Aseprite のツールで描き込めるようになります。セルは絵のある範囲に切り詰められ、レイヤーの緑色も外れます。**編集 > 元に戻す**(Ctrl+Z)で曲線レイヤーに戻せます。

## 補足

- 線のデータはセルに保存されるので、`.aseprite` ファイルに残ります。PNG などほかの形式で保存すると、ピクセルしか残りません。
- 曲線レイヤーを移動ツールで動かしても、線のデータも一緒に動きます。
- 新しいフレームやコピーしたセルにも線のデータが引き継がれます。フレームをコピーして、次のポーズに合わせて線を直す、といった使い方ができます。リンクセルは同じ線を共有します。
- 曲線レイヤーのフレームがほかの方法で変更されている(手で描き足した、フィルターをかけた、など)ときは、その変更がうっかり消えないように、すぐには編集できません。**レイヤー > 曲線を編集** を使うと、確認のあとで線のデータから描き直します。
- 以前のスクリプト版ベジェ曲線で作った曲線レイヤーも、そのまま使えます。スクリプトフォルダの古い `ベジェ曲線.lua` は削除してください。
- 点とハンドルは曲線レイヤー自体に描かれるので、上のレイヤーに隠れたり、レイヤーの不透明度やレイヤーモードの影響を受けたりします。

## できないこと

Aseprite のスクリプトは、キャンバスの上に補助線を描いたり、キャンバス上で押されたマウスボタンや修飾キーを知ったりできません。そのため点とハンドルはピクセルで表示し、点の削除・角の作成・線の描画の終了は、右クリックや Alt の代わりにパネル・Delete キー・Enter・Esc で行います。ハンドルの位置はピクセル単位になります。

クリックのすぐあとに続けてクリックすると、ダブルクリックとして扱われて無視されることがあります。近くに点を続けて置くときは、少し間をあけてクリックしてください(編集中は、環境設定の **ダブルクリックでグリッドタイルを選択する** をオフにし、終わると元に戻します)。

[`src`](src) フォルダから拡張機能のファイルを作り直すときは、`python3 build.py` を実行します。

## 動作環境

Aseprite v1.3 以降。

## ビルド

拡張機能のコードは [`src`](src) にあります。`python3 build.py` を実行すると、ライセンスと一緒に `bezier-curve.aseprite-extension` にまとめます。
